# MIDROC website preview

This repository publishes the complete redesigned English MIDROC website preview through GitHub Pages.

Pages included: Home, About, History, Industries, six industry detail pages, Leadership, News, Contact, Community, and Governance.

Visitors can browse the full site and leave feedback through the repository's Issues tab.

## Move hero text visually

Add `?heroEditor=1` to any page URL to open the cursor-based hero editor. For example: `index.html?heroEditor=1`.

Drag the outlined hero text directly to place it. Desktop and phone placements save separately in that browser. Use **Reset this view** to undo the current screen-size placement, or **Download placements** to save a JSON file that can be shared and applied to the site.
